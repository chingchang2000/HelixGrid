These guides use the easiest setup: Docker Compose for the coordinator/workers and the Python CLI for submitting workflows.

> **Security note:** HelixGrid workers execute commands from submitted workflows, and the coordinator currently has no authentication layer. Keep port 8080 on a trusted/local network unless you add authentication and proper network protection.
